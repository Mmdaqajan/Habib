# حبیب (Habib)

> **نصب اپلیکیشن Android نسخهٔ ۰٫۱:** [دانلود APK](https://github.com/Mmdaqajan/Habib/raw/refs/heads/mobile-version/apk/habib-mobile-v01.apk)
>
> این نسخهٔ آزمایشی برای Android 8.0 (API 26) و بالاتر است. پس از دانلود، فایل را باز کنید و در صورت درخواست Android، اجازهٔ نصب از این منبع را فعال کنید.

حبیب برای ثبت سادهٔ عادت‌ها، دیدن روند پیشرفت و ساختن تغییرهای کوچک و ماندگار طراحی شده است. مخزن شامل دو برنامهٔ مستقل است: نسخهٔ وب Django و اپ بومی Android. داده‌های این دو نسخه با هم همگام نمی‌شوند.

## قابلیت‌ها

### نسخهٔ وب

- ساخت، ویرایش و حذف عادت‌های تیک‌زدنی و عددی؛ عادت عددی می‌تواند واحد، بازهٔ حداقل/حداکثر و مقدار پیش‌فرض اختیاری داشته باشد.
- ثبت انجام عادت، یا علامت‌گذاری آن به‌عنوان «انجام ندادم». ثبت عادت برای تاریخ‌های گذشته ممکن است؛ تاریخ آینده قابل انتخاب نیست.
- تقویم فعالیت، آمار عادت‌ها و نمودار مقدار عادت‌های عددی. عادت تیک‌زدنی آمار تعداد روزهای انجام و بیشترین تداوم را نشان می‌دهد.
- دستاوردهای XP و مسیر مشاهدهٔ کاپ‌ها.
- یادآوری‌های روزانه، هفتگی، ماهانه و سالانه، همراه توضیح و پیش‌آگاهی؛ رویدادهای رنگی در تقویم شمسی نیز قابل افزودن، ویرایش و حذف‌اند.
- تنظیمات یک پروفایل محلی شامل نام، ایمیل، تلفن، عکس و تاریخ تولد شمسی؛ سن محاسبه می‌شود و تاریخ تولد، یادآوری سالانه با یک هفته پیش‌آگاهی ایجاد می‌کند.
- بازیابی عادت‌های حذف‌شده از بخش بازیابی.

### اپ Android

- ثبت و مدیریت عادت‌های تیک‌زدنی و عددی؛ نمودار عادت عددی با مقیاس متناسب با بازهٔ آن و شبکهٔ فعالیت ۱۲۰روزه.
- تقویم شمسی، رویدادهای رنگی و مرور یادآوری‌ها بر اساس بازهٔ زمانی.
- پروفایل محلی و یادآوری تولد سالانه؛ همچنین امکان زمان‌بندی یک اعلان یک‌باره.
- داده‌ها در SQLite خصوصی همان گوشی نگه‌داری می‌شوند. اپ برای استفادهٔ روزمره به سرور یا اینترنت وابسته نیست، اما با نسخهٔ وب همگام‌سازی نمی‌شود.

یادآوری‌های عادی در Android هنوز به‌طور خودکار اعلان سیستم‌عامل زمان‌بندی نمی‌کنند. زمان اعلان یک‌باره و تولد ممکن است به‌دلیل محدودیت‌های باتری Android کمی با تأخیر نمایش داده شود. داده‌های محلی پس از حذف اپ قابل بازیابی نیستند.

## اجرای نسخهٔ وب

پیش‌نیاز: Python و pip. در Windows PowerShell از ریشهٔ مخزن:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py manage.py migrate
py manage.py runserver
```

سپس به `http://127.0.0.1:8000/` بروید. پایگاه دادهٔ توسعه SQLite (`db.sqlite3`) است. برنامه با تنظیمات پیش‌فرض مخزن برای انتشار عمومی آماده نیست؛ تنظیم `SECRET_KEY`، `DEBUG` و `ALLOWED_HOSTS` را برای محیط عملیاتی ایمن کنید.

آزمون‌ها و بررسی تنظیمات:

```powershell
py manage.py test
py manage.py check
py manage.py makemigrations --check --dry-run
```

## ساخت و نصب APK

پیش‌نیاز ساخت: JDK 17، Android SDK Platform 35 و Build Tools 35. از ریشهٔ مخزن در Windows PowerShell:

```powershell
.\android\gradlew.bat -p .\android copyMobileV01Apk
.\android\gradlew.bat -p .\android lintDebug
```

فایل خروجی `apk/habib-mobile-v01.apk` است. این APK از نوع debug و با کلید توسعه امضا شده؛ برای تست مناسب است، نه انتشار در فروشگاه‌ها. انتشار عمومی باید با نسخهٔ release و کلید امضای اختصاصی انجام شود. برای نصب از GitHub، دکمهٔ دانلود بالای همین صفحه را بزنید؛ ممکن است Android اجازهٔ نصب از منبع دانلود را بخواهد.

## ساختار پروژه

- `apps/habits/`: عادت‌ها، ثبت‌های روزانه، نمودارها و آمار.
- `apps/alerts/`: یادآوری‌ها و رویدادهای تقویم.
- `apps/users/`: پروفایل و دستاوردها.
- `apps/recovery/`: بازیابی عادت‌های حذف‌شده.
- `android/`: کد اپ بومی Android.
- `apk/`: فایل APK قابل دانلود.
- `config/` و `templates/`: تنظیمات و قالب‌های Django.

برای جزئیات معماری، رفتار آفلاین، اعلان‌ها و فرایند ساخت، [مستندات پروژه](./docs.md) را ببینید.
